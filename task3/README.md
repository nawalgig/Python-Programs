# Task 3 — Python Programming

## Overview

This repository contains my solutions for **Task 3 of the Python Programming course**. The task focuses on practicing Python data structures, list operations, tuples, sets, dictionaries, user input, and basic calculations.

## Topics Covered

* Lists and list manipulation
* List slicing
* Adding, removing, and replacing list elements
* Sorting lists
* Finding minimum and maximum values
* Tuples and tuple operations
* Dictionaries
* Sets and unique values
* Converting dictionaries into lists of tuples
* User input
* Basic calculations and averages
* Combining sets using the `|` operator
