# 🐍 Python Core Concepts & Logic Lab (Task 2)

Welcome to the **Python Programs** repository! This project documents my hands-on practice with Python inside a Jupyter Notebook environment, moving from core mathematical and logical operators to intermediate-level real-world automation scripts.

---

## 🚀 Key Modules & Project Highlights inside `task_2.ipynb`

### 1. Operations, Variables & Shortcuts
* **Optimized Math Engine:** A streamlined basic calculator (`+`, `-`, `*`, `/`) written with minimal code lines and direct math logic.
* **Smart Balances & Gauges:** Implements asset modification tools like an E-Wallet expense manager, a Bank Account simulation, and a Water Tank depletion monitor using shortcut assignment operators (`+=`, `-=`).
* **Exponent & Boundary Evaluators:** Scripts using exponentiation (`**`), magnitude comparisons (greater/lesser), and modulus (`%`) to find exact numerical divisibility.
* **Branchless Multipliers:** A programmatic exercise that uses boolean-to-integer typecasting to apply customer discounts based on `yes/no` inputs—completely avoiding `if-else` branches.

### 2. Time-Sensitive Logic & System Gateways
* **📅 Expiry Date Tracker:** Uses Python's native `datetime` and `timedelta` modules to parse raw strings, project precise future expiration limits, and output clean calendar metrics via `strftime()`.
* **⏱️ Code Performance Benchmarker:** Employs high-resolution `time.perf_counter()` to trace execution times down to nine decimal places, showing how fast direct algebraic formulas process compared to loops.
* **🔐 OTP Verification System:** A live terminal transaction simulator using `time.time()`. It generates a random 6-digit verification code using `random.randint()` and automatically self-destructs/expires the transfer if the user doesn't enter it correctly within a strict 10-second window.
