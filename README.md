# Python Programs 🐍

Welcome to my Python learning repository! This space contains a collection of simple yet functional Python programs built while practicing syntax, logic building, and problem-solving.

## 🛠️ Concepts Covered
- **Basics:** Print statements, string formatting (`f-strings` & `.format()`).
- **Variables & Data Types:** Typecasting (`int`, `float`), dynamic swapping, and input handling.
- **Operators:** Arithmetic (`+=`, `-=`, `**`), Modulus (`%`), and Case-insensitive Logical Operations.
- **Intermediate Systems:** E-Wallet tracker, Gym Fee Calculator (No-If logic), Expiry Date Tracker (`datetime`), Performance Timer (`time`), and an OTP Verification System.
