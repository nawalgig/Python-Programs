# Task 1 – Python Fundamentals

## 📌 Overview

This repository contains the solutions for **Task 1**, focused on practicing the fundamental concepts of Python programming. The task includes exercises related to variables, reassignment, valid variable naming, string manipulation, user input, formatted output, swapping variables, print statements, and basic Python syntax.

All questions have been solved using Python and the complete implementation is available in the accompanying Jupyter Notebook (`.ipynb`) file.

## 🎯 Objectives

The main objectives of this task are to:

* Understand how to create and use variables in Python.
* Practice assigning and reassigning variable values.
* Identify valid and invalid Python variable names.
* Perform variable swapping without using a third variable.
* Work with strings and string concatenation.
* Use **f-strings** and the `.format()` method for formatted output.
* Take information from users using the `input()` function.
* Practice single and multiple `print()` statements.
* Control the formatting of printed output.
* Perform basic operations using multiple variables.

## 📝 Topics Covered

The task covers the following Python concepts:

1. **Variables and Assignment**

   * Creating variables and assigning values.
   * Reassigning existing variables.

2. **Variable Naming Rules**

   * Identifying valid and invalid Python variable names.
   * Understanding the use of letters, numbers, and underscores in variable names.

3. **Variable Swapping**

   * Swapping values between two variables without using a third variable.
   * Swapping values between multiple pairs of variables.

4. **String Operations**

   * Storing strings in variables.
   * Concatenating first and last names.
   * Working with user-provided text.

5. **User Input**

   * Taking name, age, city, email, product, and price/cost as input using `input()`.

6. **Formatted Strings**

   * Using **f-strings**.
   * Using the `.format()` method.
   * Creating formatted sentences and receipts.

7. **Print Statements**

   * Printing multiple values in a single line.
   * Using multiple `print()` statements.
   * Controlling separators and output formatting.

8. **Countdown and Sequential Output**

   * Printing numbers in sequence.
   * Creating a countdown from 5 to 1.
   * Printing programming languages using custom separators.
